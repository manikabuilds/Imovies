🎬 IMovies – Movie Ticket Booking Made Simple

About the Project

IMovies is a movie ticket booking web application that allows users to explore movies, check showtimes, select seats, and book tickets through a simple and user-friendly interface.

Features

- 🎥 Browse movies and view details
- 🔍 Search for movies
- 🕒 Explore showtimes
- 💺 Select seats
- 🎟️ Book movie tickets
- 📱 User-friendly interface

Tech Stack

- HTML
- CSS
- JavaScript
- React.js
- Node.js
- Express.js
- MongoDB

Objective

To make movie ticket booking simple and convenient through an interactive web application.
